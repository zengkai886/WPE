## 原行为细节

- UTF-8 BOM、XML 声明、CRLF、两空格缩进、字段顺序、Type 枚举名、空节点和完整十六进制均与原程序集黄金字节比较。
- 打开保存框时仅固定导出成员及顺序。随后编辑同一 PacketInfo 的 Socket/字节，待导出内容也同步更新。原版 ToList 是浅复制，不能错误冻结旧字节。
- 待处理计划保留在数据线程，宿主只拿内部 token 和元数据；一次写入消费、取消释放，内部接口不注册给浏览器。
- 选中文件路径只来自原生保存框，浏览器传入 _filePath 不生效。最多 8 个等待选择任务、16 个待导出计划；过载明确失败，不排无限内存队列。
- 保存选择框取消不写文件。桥发送失败、超时、ok:false、导航/退出取消不当作“不加密”。原 Vue 密码框 **Esc 返回成功 null，与“不加密”完全一样，因此按原行为会导出明文**，本段没有改前端消除此既有行为。
- 非空密码目前明确拒绝并显示错误，**不会静默写成明文**。加密导入/导出与密码验证尚未实现。
- 目标同目录临时文件写完/刷新后才替换。覆盖已有文件保留 DACL 与受保护标志；临时内容写入前应用原 DACL。ReplaceFile 不忽略权限合并错误，失败恢复不覆盖仍存在的目标，恢复失败保留备份路径供取回；成功删除备份。常见占用/坏数据路径已测，不承诺断电或所有文件系统异常均可原子恢复。

## 剪贴板实现与边界

专用线程拥有消息窗口，执行 OpenClipboard/GetClipboardData/SetClipboardData，并泵 Windows 消息，避免阻塞其他程序更换剪贴板。队列 32 项，忙状态最多 10 次尝试、间隔约 100ms；不是在 WebView 回调里 Sleep。读取可能等待其他程序延迟渲染，此等待不占用 UI 线程；程序关闭仍等待已开始的系统调用结束。没有强行终止线程。

空/null 写入清空剪贴板。失败写入返回 ok:false；读取失败返回空文本，保持原 RPC 契约。**原 Vue 个别复制入口不检查 ok:false 就显示成功提示**，这是保留的前端行为，不能据此将外部争用场景宣称完全体验通过。未增加剪贴板监控、日志或后台自动采集。
