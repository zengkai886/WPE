## 兼容实证

`tests/data_oracle/ConfigFileOracle.cs` 调用用户原始未改动 .NET Framework 程序集的加载器、序列化器、EncryptXMLFile / DecryptXMLFile。产出四父列表、原五组历史备份、ProxyMode/InjectMode、WhiteList/BlackList 九组增量黄金 XML，49 个密码密文向量，系统配置 null→空字符串导入前后样本。包含中文、emoji、NUL、空格密码，原系统 ACP=936。另由原程序集从原生 SQLite 实际加载 ProxyMode/InjectMode 以及 WhiteList/BlackList；原程序也实际解密了本轮原生导出的加密 `.wl`。

加密格式是旧版兼容算法：系统 ACP→MD5→摘要中间八字节大写十六进制 ASCII 密钥，AES128 CBC/PKCS7，IV=key，无文件头。**不宣称现代安全强度**；加密前不写明文临时文件。其它系统代码页应重新运行原 oracle；不能将这些 ACP936 密码向量视为任意平台结果。

当前配置专项 274 项检查，包括 ProxyMode/InjectMode 与 WhiteList/BlackList 原黄金字节、九组备份顺序、RPC/SQLite 持久化、旧库补列、设置/IP 范围/日期校验、本机地址不带虚假 `:0` 端口，以及既有双向 AES、重复 GUID、错误密码、一次性 token、取消、选择/全部导出、对象别名、空/缺失分组、未支持组拒绝、真实 SQLite 中途失败回滚、worker 排队导入取消、前缀命名空间/非标准根名/混合字段文本/尾分隔符。

原 Vue / 真 WebView2 自测覆盖：原导出按钮、密码框加密导出、原清空按钮和确认框、原导入按钮、错误密码→留窗→正确密码、选文件前/伪造路径/消费后验证拒绝、保存后重启。文件选择仍是隔离固定路径 seam，不冒充 Windows 选择框 UI 验收；UI 剪贴板用隔离内存，OS 剪贴板另在私有 window station 测试。四父列表与备份的每个可见按钮组合尚需最终完整 GUI 验收。

## 审查与差异

独立 Standards / Spec 审查发现并修复：明文 import token 未登记导致取消后执行；XML 子树重写丢 namespace 和混合文本；枚举/功能标志尾空字段丢失；父对象恢复后旧编辑会话误绑定；额外根名限制拒绝原版可加载文件。对应回归已收入专项测试。

原版会吞掉部分 XML/数据库错误并可能部分应用，本实现非法字段/未支持分组整批失败；这是明确错误处理边界，不能宣称任意坏文件输入行为完全一样。DTD 仍禁止、元素深度限制 64、文件最大 INT_MAX。原 Vue 导出密码框 Esc 成功返回 null 仍等同“不加密”；桥失败/超时不等同该选择。
