原版格式关键点：

- 系统 ACP 编码密码（本机原 .NET Encoding.Default=936），MD5 后取 digest[4..11] 的大写十六进制 16 字符作为 ASCII 密钥；AES-128 CBC PKCS7，IV=key，原始密文无头。这只是旧格式兼容，不是现代安全设计。
- XML UTF8 BOM、standalone=yes、CRLF、2 空格缩进；空字符串与 null 标签形态不同。普通列表导入追加，重复 GUID 重建；备份只替换存在的分组，缺失保持，空分组清空。
- Filter 的 Guid.Empty 能导入，其余三种父列表跳过；Send 导入/导出 SystemSocket 始终 false，父列表导出不带 IPFrom；机器人导入不套编辑器内容校验；仓储内容为十六进制且受容量上限裁剪。
- 父列表布尔 True/False，系统配置布尔 true/false。已有 65 个系统字段、27 个滤镜字段按原文件顺序提取。
- Vue 导出密码框成功返回 null（包括 Esc）表示“不加密”；桥接失败/超时/导航取消绝不能降级成明文导出。加密导出不能先写明文临时文件。
- 密码验证只能用当前原生文件选择器授予的 token 与路径；不得开放浏览器任意路径读取。导入内容选择后在 worker 缓存，验证/应用针对同一字节内容；取消/关闭/队列满释放计划。
- 普通导出冻结成员及顺序，但原 PacketInfo/父对象字段的浅拷贝别名要保留；备份在密码框完成后读取实时状态。备份整批替换不应改旧导出快照的对象身份。
